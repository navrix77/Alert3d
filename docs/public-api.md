# SKY · публічний API v1 (для інтеграцій)

База: `https://sky.navryx.com.ua/api/public/v1` · авторизація: заголовок `X-API-Key: <ключ>` · ліміт 30 запитів/хв на ключ (429 + `Retry-After`).
Формат версійований (`"v": 1`): поля додаватимуться, наявні не змінюватимуться без нового `/v2`.

> Дані НЕОФІЦІЙНІ: оцінка за відкритими джерелами, можлива неповнота/помилки. Для рішень про безпеку первинним лишається офіційне оповіщення.
> Завжди перевіряйте `fresh` і `age_s`: якщо `fresh=false` або дані застарілі — показуйте це користувачам.

## GET /state
```json
{"v":1,"now":1794399411,"fresh":true,"alert_regions":["Харківська"],
 "targets":[{"id":"РБ-1","type":"jet","name":"Реактивний БпЛА","count":null,"lat":49.99,"lon":36.27,
   "heading_deg":225,"speed_kmh":450,"status":"active","position_is_estimate":true,"position_error_km":22,
   "confidence":0.5,"independent_sources":3,"next_place":"Харків","age_s":40}],
 "disclaimer":"…"}
```
`type`: shahed, jet, molniya, cruise, ballistic, banderol, kab, geran5, fpv… · `status`: active|lost (закриті не віддаються).
`position_is_estimate=true` — точка розрахована, а не названа каналами; `position_error_km` — типова похибка.

## GET /near?lat=..&lon=..&r=50
Цілі в радіусі `r` км (1–300) за відстанню + `nearest_km` (null, якщо немає).

## Коди
200 · 401 невірний/відсутній ключ · 429 ліміт · 503 API вимкнено (немає ключів на сервері).

## Рекомендації для клієнта
Опитуйте не частіше ніж раз на 10–15 с; кешуйте; не віддавайте ключ у браузер (запит із вашого сервера); при помилці/застарілих даних показуйте «дані недоступні», а не «безпечно».
