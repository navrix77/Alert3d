# Як SKY читає пости (правила, закріплені тестами у `tests/test_posts_corpus.py`)

| Фраза у пості | Що це означає | Що робить SKY |
|---|---|---|
| «над X», «в X» | ціль зараз у X | реальна позиція в X |
| «на X» (без місця) | X — мета, позиція невідома | оцінка біля X; курс **від кордону/фронту**, не до нього |
| «на X з півночі» | підходить з півночі | позиція на підході (≈14 км на північ від X), курс на південь; «над X» від каналу ставить у центр |
| «від A на B» | звідки A, куди B | позиція біля A, курс на B (не в B) |
| «курсом на X з Y-щини» | пущено з області Y | курс від центру області Y до X |
| «на X», коли трек уже має реальну фіксацію і X далі 12 км | інша ціль | окремий трек, не перенацілення |
| ціль над містом-метою | удар по місту | без «ймовірно далі» (виходу з міста) |
| FPV і шахед в одній точці (≤5 км) від різних каналів | один об'єкт | зливаються |
| «упав / збито над X» | ціль завершена | трек закривається |

Зони пуску (запасний курс без підказок каналів): `app/launch_zones.py` — Крим, Білгородська, Курська, Брянська області, Азов, Воронеж; дальність за типом.

Самоаудит: `/api/audit` → `no_place` (невпізнані місця), `heading_reversed` (показаний курс протилежний реальному руху), `teleport`, `far_course`, `off_region`.
Кожна помилка, яку помітив власник, стає рядком у цій таблиці й тестом.

## Самонавчання словника (08.11)
Слова, яких бот не впізнав у постах («на X» без місця), пишуться в `/api/audit` (kind `no_place`). Щоночі (03:40 Київ, після тренера) `python -m app.dictlearn`:
слово з ≥2 різних постів у каналі певної області → пошук в OSM (Nominatim) у межах міста цієї області (з перевіркою схожості назви) → `data/learned_places.json`;
`parser.reload_learned()` підхоплює файл без перезапуску. Негативні відповіді кешуються на 7 діб (`learned_negative.json`).
