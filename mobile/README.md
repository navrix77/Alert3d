# «Тривога» — мобільний клієнт (React Native + Expo)

Нативний клієнт агрегатора повітряних загроз «Тривога» для iOS та Android. Він не використовує WebView: карта MapLibre Native, скляні панелі, анімації на пружинах і жести працюють нативно.

## Що вміє

- **Карта:** супутникова підкладка Esri World Imagery. Райони й області заливаються **лише за офіційними тривогами** (`official.raion_levels`, `official.points`, `official.levels`): рівень 2 — `#C8102E`, рівень 1 — `#E8B300`.
- **Живі цілі:** спрайти повертаються за курсом. Позиція щокадру екстраполюється вздовж маршруту зі швидкістю цілі між пушами сервера (логіка `posAt()` з `web/app.js`). На карті є значок ×N, підпис «→ наступний пункт», пунктирний слід і штриховий ланцюжок пуску (місце пуску → перша фіксація → ціль). Для вибраної цілі видно прогноз маршруту й позначки +5/+10/+15 хв.
- **Картка цілі** (нижній аркуш): тип, курс, відстань і час до дому, ETA по пунктах маршруту, блок «Звідки запущено» (місце, носій, час пуску, «ймовірно» для оцінок) і джерела підтвердження з посиланнями на пости. Є також режим «Стежити».
- **«Мій дім»:** довге натискання на карту ставить дім (зберігається в AsyncStorage). Верхня скляна панель показує статус-сферу (Skia), найближчу загрозу й хвилини до неї. Якщо підтверджена ціль маршрутом або курсом проходить ближче ніж за 15 км від дому, телефон вібрує й показує локальне сповіщення.
- **Налаштування** (кнопка ⚙︎): адреса сервера (за замовчуванням `http://192.168.1.100:8090`, це заглушка), стан зʼєднання, скидання дому.
- **Зʼєднання:** WebSocket `/ws` з автоперепідключенням (пауза зростає від 1 до 15 с) плюс початковий `GET /api/state`. Якщо даних немає понад 20 с, зʼявляється банер «Немає звʼязку — це не відбій».

## Вимоги

- Node.js 20+ (перевірено на 22).
- Для **development build**: Android Studio (Android) або Xcode на macOS (iOS), або обліковий запис EAS.

> ⚠️ **Expo Go не підійде.** `@maplibre/maplibre-react-native` та `@shopify/react-native-skia` мають власний нативний код, якого в Expo Go немає. Потрібна **development build**.

## Запуск

```bash
cd mobile
npm install

# 1) один раз зібрати нативний застосунок (development build)
npx expo prebuild            # згенерує android/ та ios/
npx expo run:android         # або: npx expo run:ios   (потрібен macOS + Xcode)
#   …або в хмарі через EAS:
#   npx eas-cli@latest build --profile development --platform android

# 2) далі для щоденної роботи досить dev-сервера Metro
npx expo start               # відкрийте зібраний застосунок «Тривога» на телефоні
```

Перевірка типів: `npx tsc --noEmit`.

## Сервер

1. **Телефон і компʼютер мають бути в одній мережі Wi‑Fi.**
2. Сервер має слухати всі інтерфейси, а не лише `127.0.0.1`:

   ```bash
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8090
   ```

   `start.bat` зараз запускає сервер без `--host 0.0.0.0`, тобто лише для `localhost`, і телефон до нього не достукається. Запустіть команду вище вручну або допишіть `--host 0.0.0.0` у `start.bat`. Інший варіант — розгорнутий сервер (Cloud Run тощо) з адресою `https://…`.
3. Дізнайтеся IP компʼютера в локальній мережі (`ipconfig` у Windows, `ip a` або `ifconfig` у Linux/macOS) і впишіть у застосунку: ⚙︎ → «Адреса сервера», наприклад `http://192.168.1.23:8090`.
4. Якщо не підключається, перевірте брандмауер Windows: він має дозволяти вхідні зʼєднання на порт 8090.

Звичайний HTTP у локальній мережі дозволено конфігурацією (`usesCleartextTraffic` на Android, `NSAppTransportSecurity` на iOS).

## Структура

```
App.tsx                         корінь: провайдери, верхня панель, кнопки, аркуші
src/lib/types.ts                типи JSON сервера (/api/state, /ws)
src/lib/geo.ts                  проєкція, posAt(), homeRel(), ETA маршруту, точка-в-полігоні
src/lib/display.ts              плавні відображувані позиції (DISP), цілі біля дому
src/lib/theme.ts                кольори, назви типів, константи
src/hooks/useLiveState.ts       WebSocket + перепідключення, зсув годинника сервера
src/hooks/useSettings.tsx       адреса сервера й дім (AsyncStorage)
src/hooks/useHomeAlerts.ts      вібрація + локальні сповіщення (≤ 15 км від дому)
src/components/TacticalMap.tsx  карта, райони/області, зони, дім
src/components/LiveLayers.tsx   кадровий цикл: цілі, сліди, ланцюжки пуску, прогнози
src/components/HomePanel.tsx    скляна панель «Мій дім»
src/components/StatusOrb.tsx    анімована Skia-сфера статусу
src/components/TargetSheet.tsx  картка цілі (@gorhom/bottom-sheet)
src/components/SettingsSheet.tsx налаштування
src/components/OfflineBanner.tsx банер «немає звʼязку»
src/components/Glass.tsx        скляна панель (expo-blur) і кнопка на пружині
assets/sprites/                 спрайти цілей (копія web/sprites, ніс угору)
```

## Обмеження

- Справжнє розмиття фону працює на iOS. На Android під картою MapLibre (GL-поверхня) системне розмиття недоступне, тому панелі там мають напівпрозору темну підкладку.
- Сповіщення локальні: вони приходять, лише поки застосунок працює (на передньому плані або щойно згорнутий). Фонового відстеження й push-сервера немає.
- Підписи на карті використовують гліфи OpenFreeMap (`tiles.openfreemap.org`), тож для них потрібен інтернет.
